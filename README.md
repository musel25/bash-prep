# bash-prep

Drilling Bash + Unix command-line fundamentals to pass technical screens.

A **learning-first** project: the goal is understanding, not output. Working code is
evidence that a concept landed — never the other way around.

## How this works

Sessions are driven by learning-kit skills:

- `/map`   — discovery interview when the next direction is fuzzy.
- `/slice` — build one small, runnable vertical slice end-to-end.
- `/spike` — throwaway experiment to settle a single unknown.
- `/teach` — explain a concept properly, ending with a check question.
- `/recap` — honest end-of-session summary.
- `/review` — skeptical senior review of recent changes.

See [`CLAUDE.md`](./CLAUDE.md) for the full learning contract and [`PLAN.md`](./PLAN.md)
for the current goal, slices, and decisions.

## Starting point

Comfortable with `cd`, `ls`, basic `grep`. Everything else — pipes, redirection, quoting,
exit codes, `find`, `awk`/`sed`, scripting, permissions — is new. Building from the ground up.
